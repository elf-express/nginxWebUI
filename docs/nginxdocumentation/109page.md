## Compatibility

This page describes the JavaScript surface provided by njs:

-   the njs and nginx objects, built-in modules, and the `Buffer` object, available with both the [QuickJS](https://nginx.org/en/docs/njs/engine.html#quickjs_engine) and [njs](https://nginx.org/en/docs/njs/engine.html#njs_engine) engines;
-   the ECMAScript language features implemented by the [njs](https://nginx.org/en/docs/njs/engine.html#njs_engine) engine.

Definitions of njs specific properties and methods not compliant with ECMAScript can be found in [Reference](https://nginx.org/en/docs/njs/reference.html). Definitions of standard ECMAScript objects and methods can be found in the [ECMAScript specification](http://www.ecma-international.org/ecma-262/).

#### ECMAScript compliance (njs engine)

> The ECMAScript language features listed below describe the [njs](https://nginx.org/en/docs/njs/engine.html#njs_engine) engine, which is deprecated since [1.0.0](https://nginx.org/en/docs/njs/changes.html#njs1.0.0). The [QuickJS](https://nginx.org/en/docs/njs/engine.html#quickjs_engine) engine supports ES2023; new code should use the QuickJS engine instead.

The njs engine is implemented in compliance with [ECMAScript 5.1](http://www.ecma-international.org/ecma-262/5.1/) (strict mode) with some [ECMAScript 6](http://www.ecma-international.org/ecma-262/6.0/) and later extensions. The compliance is still evolving.

-   Boolean values, numbers, strings, objects, arrays, functions, function constructors ([0.3.6](https://nginx.org/en/docs/njs/changes.html#njs0.3.6)), and regular expressions
-   ES5.1 operators, ES7 exponentiation operators, ES2020 optional chaining ([0.9.6](https://nginx.org/en/docs/njs/changes.html#njs0.9.6)), ES2021 logical assignment operators `||=`, `&&=`, `??=` ([0.9.6](https://nginx.org/en/docs/njs/changes.html#njs0.9.6))
