## 設定檔計量單位

nginx 設定中可用多種單位表示**大小／位移**與**時間間隔**。

### 大小與位移（Sizes and offsets）

大小可用位元組，或以尾碼表示 KB / MB：

| 尾碼 | 意義 |
|------|------|
| `k`, `K` | kilobytes |
| `m`, `M` | megabytes |

例如：`1024`、`8k`、`1m`。

位移還可用 GB：`g` 或 `G`。

### 時間間隔（Time intervals）

| 尾碼 | 意義 |
|------|------|
| `ms` | 毫秒 |
| `s` | 秒（**無尾碼時的預設**） |
| `m` | 分鐘 |
| `h` | 小時 |
| `d` | 天 |
| `w` | 週 |
| `M` | 月（以 30 天計） |
| `y` | 年（以 365 天計） |

可從大到小組合多個單位，空白可有可無。例如 `1h 30m` 等同 `90m` 或 `5400s`。

- 無尾碼的數值表示**秒**。
- **建議永遠寫尾碼**，避免與「分鐘 `m`」混淆。
- 部分時間參數只能用「秒」解析度。
